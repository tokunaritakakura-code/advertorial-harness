## 日本の買い手の癖（行動科学で言うと何か）

| 癖 | 原理 | 記事・PDPでの形 |
|---|---|---|
| 条件が1つでも曖昧だと買わない | 不確実性の回避（Hofstedeの指数で日本92、米国46） | 返送料・回数・日数・向かない靴の4つを全部書く。曖昧な語で締めない |
| 損する可能性を先に計算する | 損失回避（得より損が2倍重い） | 「外した時の損」を先に小さくする。返金条件を価格より先に |
| 「みんな買っている」で安心する | 社会的証明・同調 | 件数と「いちばん選ばれている段」。ただし件数は3か所で揃える |
| 権威は信じるが、売り手の権威は疑う | 権威＋利益相反の検知 | 医師を「監修」に置き、評価は書き手がつける。中立でないと本人に言わせる |
| 公式・正規・日本語サポートで安心する | 安心の信号 | 「メーカー公式」「Amazon・楽天にない理由」「年中無休サポート」 |
| 締切に反応するが、偽の締切は見抜く | 希少性 vs 信頼 | 在庫の希少性だけ使う。時計は使わない |
| ランキング・検証・比較の形を信じる | 認知の流暢性・第三者の形 | 360LiFE型（目次・監修・テスト方法・比較表・A評価・Q&A） |
| 他人の目（臭い・靴を脱ぐ場面） | 恥の回避 | 蒸れ・臭いを独立した節に |
| 支払いはカード以外を使う人がいる（件数は未実測） | 手数の削減 | 後払い・コンビニ払い（PDPの穴A） |
