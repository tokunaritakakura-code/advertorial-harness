## 見えたパターン（深さのルール）
1. 飛び先が商品ページ → VSL が原因・仕組み・成分・オファーまで全部言い切る（J・L・I・G）
2. 飛び先がリスティクル → VSL は「今の物はだめ」と原因まで言い切る。商品の良さ（理由N個）・比較・証拠は記事へ回す。VSL で「いいえ」とだけ言った物を、記事が1つずつ証明する（Veloma・Everly・Koriderm）
3. 飛び先が VSL ページ → VSL は原因まで言い、解決策は名前だけ（「7秒の流し方」「あるミネラル」）。中身は記事へ＝好奇心の穴（VitalBP・Morning Vitality）
4. 飛び先が物語のアドバトリアル → VSL と同じ原因を、別の語り手（「私」「ジェシカ」）でもう一度話し、研究と週ごとの変化を足す（Sculptique・Hike・Rosalivia）
5. 研究の扱い → VSL では数字1つ（94%・1200人・UCLA）だけ。研究の中身は記事側で足す余地がある
6. 物語が長い形式（タブーの物語・ドラマ）ほど、VSL の中の説明は短く（1〜2行）、記事で説明を全部やる
