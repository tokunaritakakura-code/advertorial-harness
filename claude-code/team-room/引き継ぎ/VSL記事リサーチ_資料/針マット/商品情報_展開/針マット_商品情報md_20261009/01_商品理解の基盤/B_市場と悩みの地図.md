# B. 日本の市場と悩みの地図（針マット）

作成：2026-10-07。商品理解の基盤のB。針マットは、布のマットに針のようなプラスチック突起の円盤を並べ、寝転んで自分の体重で背中・腰を押す指圧マット（枕つき）。本書は市場と悩みの整理。

**結論**
- 腰痛と肩こりは、国の調査で男女とも自覚症状の1位と2位。人口千人あたり、腰痛は男91.6・女111.9、肩こりは男53.3・女105.4（2022年）。腰痛の人は約2,800万人で、40〜60代の約4割という推計が報道されている（2013年）。
- 長く続く。30〜40代5万人の調査で、肩こり歴は平均12.4年、腰痛歴は平均9.9年。慢性の筋骨格の痛みは成人の15.4%にあり、治療した人の7割が1年以上続けていた。
- お客さんの言葉は「朝」と「起き上がる時」に集まる。「朝起きたときに腰が痛い」「寝起きにぜっっったい身体が痛い」「起き上がる際→激痛」。昼は「ずっと座ってられない」「体中バキバキ」「こりすぎて息苦しい」。
- 責めている物の上位は ①医者・検査（「異常なし」と言われた、湿布と痛み止めだけ）②仕事の姿勢（デスクワーク・座りっぱなし）③寝具（マットレス・枕）④歳 ⑤今までの対策（整体・整形外科は無駄だった）。
- 今までの対策への言葉は1つの形にそろう。「その時は良くなるのですが数日経つと」「施術してもらった直後は楽になりましたが、その日の夜にまた痛く」「どの治療法を試しても、一瞬でも症状が消えることがありません」。
