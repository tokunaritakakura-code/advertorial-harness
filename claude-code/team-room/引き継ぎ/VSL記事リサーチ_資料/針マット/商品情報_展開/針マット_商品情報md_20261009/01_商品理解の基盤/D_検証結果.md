## 調べ方

- 論文：PubMed（E-utilities）と Europe PMC の API で抄録を取った。Olsson 2011 と Beinart 2013 は抄録の全文を原文のまま確認した。Hohmann 2012 は Europe PMC の全文（本文）で数値を確認した。ほかは抄録（取得ツールが要約して返したものを含む。数値と引用符つきの文を照合に使った）。
- 『腰痛診療ガイドライン2019』：Minds の本文 PDF を保存し、目次（p.xi）、BQ2（p.9-10）、CQ2（p.34-35）、CQ3（p.45）、CQ4（p.53-54）、CQ8（p.73-78）をページの画像で読んだ。
- 日本ペインクリニック学会 治療指針：PDF の p.123-124 を画像で読んだ。
- 国民生活センター 2016、消費者庁 2017、厚生労働省 事務連絡 2016：PDF を画像で読んだ。**国民生活センターと消費者庁の元の URL は開けなかった**（kokusen.go.jp は404、消費者庁の元ページは未取得）。自治体サイトに載っている同じ発表資料の PDF で確認した。
- 添付文書：PMDA のページ（取得ツール経由）。
- 検証役は D を書いた本人。別の人による照合はしていない。
