# H. 根本原因（針マット）— 2026-10-07 案（Seiyo の確認待ち）

作り方：`01_ルール/23_根本原因の探し方.md`（root-cause.md）の9章の形。出どころの番号は B（`B_市場と悩みの地図.md`）の #＝お客さんの言葉、責＝責めている文、M＝体の仕組みの出どころ、S＝指圧マットの試験。

## 1. 根本原因（1文）・名前・箱
- **根本原因**：同じ姿勢で固まった腰の奥の筋肉が、中を通る血管をしめつけて血を止め、酸素の足りなくなった筋肉が痛みを出し、痛いからまた固まる。この輪が、毎日回っている。
- **名前**：**筋肉の酸欠**（その場で言う一言：「血が来なければ、酸素も来ない。酸素の足りない筋肉は、悲鳴のように痛みを出す」）
- **箱**：体（体は、自然にこうなる）
- **責めている物**：医者に言われた「異常なし」・骨／仕事の姿勢／歳。対策では、湿布・マッサージ器・整体

> 筋肉の名前（脊柱起立筋・多裂筋）、胸腰筋膜のさやと内圧、その出どころ（K1〜K10）は `I_仕組みの細部.md`（2026-10-07）。根本原因の名前「筋肉の酸欠」は変えない。I は、同じ原因を部位の名前まで細かく言うための資料。

ここで止める理由：学会の治療指針（M1）が「悪循環路」として書き、治す方向も「筋肉の過緊張と循環障害…を改善する」と書いている。これより下（なぜ同じ姿勢を続けるのか）は、暮らしの話で、商品が届く所ではない。

## 6. 仕組み3〜4歩・たとえ
**仕組み（1歩＝1文）**
1. 同じ姿勢が続くと、腰の奥の筋肉は固まる
2. 固まった筋肉は、中を通る血管をしめつけ、血を止める
3. 血が来なければ、酸素も来ない。酸素の足りない筋肉は、痛みを出す
4. 痛いから、また固まる。固まるから、また血が止まる

## 7. 今までの対策が届かない理由／治すための条件／商品がどう届くか
| 対策（ヴィラン） | 何をしている物か → だから届かない | お客さんの体験（原文） | ヴィランを落とす一言のたとえ |
|---|---|---|---|
| 湿布 | 皮ふの上から、痛みの感覚を鈍らせる → 奥の筋肉はゆるまず、血も流れない。酸欠はそのまま | 「ロキソニンテープを貼ってないと痛みが酷く」（#25）「長く貼っていると『効かなくなってきたな』」（#26） | （原稿で毎回作る） |
| マッサージ器 | 当てた一点を、その時だけゆらす → 固まっているのは腰から背中までひとつながり。まわりは固いまま。持つ腕が先に疲れて、毎日は続かない | D1（出どころは D1 の表） | （原稿で毎回作る） |
| 整体 | その日の筋肉をゆるめる → 次の朝から同じ姿勢で、また固まり始める。毎日は通えない | 「いってその時は良くなるのですが数日経つと」（#29）「施術してもらった直後は楽になりましたが、その日の夜にまた痛く」（#31） | （原稿で毎回作る） |

- **治すための条件**（根本原因の裏返し。原稿では3つに分けて言う）：①固まった筋肉を、広い面で、奥まで押して、放す（血を流しこむ）②それを毎日（固まりは毎日作られる）。③そのために、手を使わず・人の手を借りずに家で出来ること
- **商品がどう届くか**：①寝転ぶと、自分の体重が、面いっぱいに並んだ針のような突起の数えきれない点に分かれて、腰から背中までを一度に押す（＝自重指圧）②家の床に敷いて寝転ぶだけなので、毎日できる ③手も、人の手も、電気もいらない
- **体の証拠（見る人の体で分かる事）**：最初はチクチク → 数分でじんわり温かい（#44「5分を超えたくらいから…ポカポカとあたたかい感覚」#46「5分ほど寝てると背中がじんわり暖かくなり」）
- **原稿の道すじ**（商品の名前を出さずに）：やる事は1つ＝固まった筋肉を押して放し、血を流す → どういう物が良いか＝広い面を・手を使わず・毎日 → どうやるか＝寝転んで自分の体重で押す → その形の道具＝面いっぱいの突起 →「それが、この針マットです」
