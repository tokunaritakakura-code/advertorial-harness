## 直す所の一覧
1. 4段「3か月」の文「やりたかった事を、またやりたくなります。」→ 戻ってくる物を具体的に言う（例「あきらめていた庭仕事や旅行を、また楽しめます。」）。
2. 3段の研究の文（1日30分・14日）の後に、家での使い方「1日10分から。慣れたら長く乗ってもかまいません」を医師の口で1文足し、30分と10分の差を埋める。
3. 7段の「収納バッグを無料でおつけします」→「セットに、収納バッグを無料でおつけします」。単品にも付けるならテスト用に決めた値.md と FAQ・値段の欄を合わせる（どちらかに1つにそろえる）。
