よくある質問

Q.漢方アドバイザーはどんな人ですか？
A.医師や薬剤師など漢方に関する知見を有するメンバーとなります。LINEで悩んでいる症状や漢方について相談することができます。
Q.どんな症状に対応していますか？
A.冷え性、肩こり、頭痛、生理痛、PMS、不妊、肥満、むくみ、更年期、不眠、食欲不振、便秘、肌荒れなどの症状に対応しています。それ以外の症状でも漢方アドバイザーとのチャット個別相談でおすすめの漢方をご提案させていただきます。LINEよりお気軽にご相談ください。
Q.いくらから始めることができますか？
A.ご予算に応じて1日服用包数や日数を変更することで最適なメニューを提案させていただきます。最低4,980円から漢方をお試しすることも可能です。LINEでのご相談や体質チェックは無料です。
Q.どれくらいで効果を実感しますか？
A.早ければ3日ほどで効果を実感する人もいますが、半年ほど継続して服用するとしっかり体質改善ができ、病気予防にもつながります。 特に最初の1ヶ月目というのは、漢方薬になじむ大切な期間ですのでまずは毎日欠かさずお飲みいただくことが改善への一番の近道です。
Q.漢方はどこから配送されますか？
A.YOJO薬店(東京都文京区本郷5丁目25−18 ハイテク本郷ビル102)より、お客様の希望の分量を調合してご郵送いたします。
Q.市販の漢方との違いは何ですか？
A.YOJOでは、通常のドラッグストアや薬局などではほとんど取り扱われず、漢方薬局でのみ販売されるような漢方を販売しております。法に定められた水準以上にいくつもの厳しい検査の行われた安全な生薬を使用した漢方ですので、安心して服用いただけます。
