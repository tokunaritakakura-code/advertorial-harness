# 形式の振り分け（manifest.tsv の1列目が vsl の広告）

読む人: vsl の広告を形式に振り分けて段に分けるエージェント。読む時: `_段分けの指示.md` の後に全部。

vsl の広告は形式がまだ決まっていない。1本ずつ、sheet（見た目）と台本（話し方）で、下の形式のどれか1つに決める。どれにも入らない時は新しい形式の名前を付ける（例: ニュース番組風・電話の録音）。

| 記号 | 形式 | 見分け方 |
|---|---|---|
| A | 権威の1人しゃべり | 医者・専門家・ナレーターが1人で説明する。白衣・肩書き |
| B | 予告編 | 解決策の名前だけ言って「発表を見て」と医者の VSL ページへ送る |
| C | ドラマ・寸劇 | 2人以上が場面の中で会話する |
| D | タブーの物語 | 1人が自分の恥ずかしい・つらい体験を長く語る（浮気・離婚 等） |
| E | 第三者の証言 | 家族・友だちが「夫が」「母が」と他人の変化を語る |
| F | 創業者 | 作った本人が語る（作った理由・偽物の注意・値段の理由） |
| G | 昔の権威 | 祖母・昔の療法・伝統 |
| H | 現場の人 | 介護施設の運営者・看護師・美容師のような、現場で働く人（医者は A） |
| I | 時間で歩く | 1日目・7日目・30日目…と使った後の変化を順に言う |
| L | 歌 | 歌っている |
| U | UGC の体験談 | 普通の客が自撮りで「私はこれを使って」と語る（A〜H に入らない物） |

決め方の順: 見た目（sheet）で C・L を先に決める → 話し手が誰か（A・E・F・G・H・U）→ 話の運び（B・D・I）。2つに当てはまる時は、台本の半分以上を占める方にする。

出力は `_段分けの指示.md` の書き方で、形式ごとに見出しを分けて1つのファイルに書く（ファイル名は任された時に指定）。形式のまとめ（出現数・型）は書かなくてよい（後で全部を合わせて数える）。広告ごとの段分けと、飛び先の型・記事の段・対応は必ず書く。各広告の見出しに形式の記号を付ける（例: `### [A] Dr. Katherine Hale 82471402（689秒・186日）→ 商品ページ`）。
