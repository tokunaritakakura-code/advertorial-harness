# 広告1本ずつの「認知の段階」と「買わない理由」を書き出す指示

読む人: この作業を任された係（7人が同じやり方で並んで作業する）。読む時: 始める前に全部。
読まなくていい条件: なし。

## 目的（本人 2026-10-09）
認知の段階ごとに、VSL が先にどの買わない理由を潰し、記事が次にどれを潰し、一番大きい理由をどんな言い方で潰しているかを、実物から集める。後で段階ごとに並べて型と言い回しのひな形にする。推測で一般論を書かない。台本と記事に書いてある言葉だけを根拠にする。

## 材料（フォルダ `形式別/`）
- `manifest.tsv`: 1行1広告（format・id・brand・days・sec・landing・lp_file・txt・sheet）
- `txt/<id>.txt`: VSL の台本（文字起こし）
- `lp/<lp_file>`: 飛び先の記事の HTML。本文は `python3 -I ../lpread.py lp/<file> 60` で出る。足りなければ python で本文の文字だけ抜く
- 既にある段分け（参考に使ってよい）: `段_*.md`（同じ id の所）

## 認知の段階（5つ。1本に1つ）
| 段階 | 見分け方（VSL の書き出しと前提で決める） |
|---|---|
| 気づいていない（Unaware） | 悩みの名前を出さずに、意外な事実・物語・場面から入る。見る人は自分の問題に気づいていない前提 |
| 問題に気づいている（Problem aware） | 悩みは名指しするが、原因や解決策はまだ知らない前提（「〇〇なのは、あなたのせいではない」「本当の原因は」） |
| 解決策を知っている（Solution aware） | 見る人がもう何かを試した前提（「ストレッチも湿布も試した」「クリームでは届かない」） |
| 商品を知っている（Product aware） | 商品やその種類を知っていて、迷っている前提（偽物・値段・効くかへの答え） |
| 買う直前（Most aware） | 値引き・セット・期限が中心 |

## 1本ずつ書く事（JSON を1行。全部の欄を書く）
```json
{"id":"…","brand":"…","段階":"問題に気づいている","段階の根拠":"台本の書き出しの引用（原文のまま）",
 "VSLで潰した理由":[{"理由":"短い日本語（客の頭の中の声。例「年のせいだから仕方ない」）","潰し方":"何をして潰したか（例 本当の原因を名指し）","引用":"台本の原文"}],
 "記事で潰した理由":[{"理由":"…","潰し方":"…","引用":"記事の原文"}],
 "一番大きい理由":"その広告が一番時間を使って潰している理由",
 "その言い方":{"原文":"一番大きい理由を潰した文（台本か記事。原文のまま）","日本語":"同じ心理の効果が出る日本語","どこで":"VSL か 記事",
  "型":"言い方の型を短く（例 権威の自白型「私は〇〇医ですが中立ではありません」／今の出費の足し算型）"},
 "値段の見せ方":"値段の段で何と比べ、どう割ったか（無ければ「なし」）",
 "飛び先の型":"商品ページ／リスティクル／物語の記事／権威の暴露記事／事前販売ページ／医者のVSLページ／オファーページ／トップページ／読めなかった"}
```
- 買わない理由の「理由」は、客の頭の中の声として書く（「本当に効くの？」「痛くない？」「値段が高い（払えない）」「もう試した」「自分には関係ない」）。同じ中身は同じ言い方にそろえる（後で数えるため）。そろえる時は下の名前を使い、無い時だけ新しい名前を作る: <!-- 掘った: 「高い」は客の頭の中の声として名前に使う言葉で、判断語ではない -->
  関係ない／年のせい／原因が分からない／治らないと思う／医者に任せる／もう試した／これも同じでは／効くか分からない／痛い・怖い／自分に使えるか／手間がかかる／偽物・安物では／値段が高い／今じゃなくていい／損したくない／信用できない <!-- 掘った: 「値段が高い」は客の頭の中の声の名前で、判断語ではない -->
- 記事が読めない時は「記事で潰した理由」を [] にし、飛び先の型を「読めなかった」にする
- 台本が英語以外でも、引用は原文のまま

## 出力
任された組のファイル（`組<N>.txt` に id が1行ずつ）の全部の id について、1行1本の JSON を `買わない理由/組<N>.jsonl` に書く。全部書いたら、`python3 -c` で各行が JSON として読めて欄がそろっているかを確かめる。
返事は3行だけ（書いた本数・読めなかった記事の数・一番多かった段階）。
