# 段階ごとのパターン（VSL 194本と飛び先の記事）

材料: 同じフォルダの `組1〜7.jsonl`。数はすべてここから python で数えた。
箱の番号: 1 自分の話か／2 原因を信じられるか／3 これで効くのか／4 信用できるか／5 自分に合うか・続けられるか／6 損しないか／7 値段と今買う理由

数え方:
- 箱の順番 = VSL の段を頭から読み、初めて潰した箱を出た順に並べた最初の3つ（同じ箱の2回目以降は数えない）
- 商品が初めて出る位置 = 「商品が出る」が最初に付いた段を、VSL 全体の長さの何割目かで分けた
- 残したなんで = VSL の最後の「残したなんで」を言葉で分けた。記事が受けた箱 = 記事で最初に箱を潰した段の1つ目の箱
- 記事の型の割合は「読めなかった」を除いた本数で割った

**2. 残したなんでと記事の受け方**

**3. 一番大きい理由を潰した言い方**（一番大きい理由は 3 効くのか 11本、4 信用 7本、1 自分の話 3本）
- 〈欠点に見える所〉が狙いだ。〈普通の物〉は〈逆効果〉、〈この物〉は〈効く〉
  例「Tastes absolutely disgusting. That's the point.」ひどくまずい。それが狙いだ。甘いサプリは寄生虫の餌になる、苦いハーブが殺す（169055597）

  例「Your toothbrush can't reach it.」歯ブラシは届かず、洗口液は違う菌を殺す（107671009）
- 〈成分〉は〈いちばん小さい〉から〈効く場所〉の中まで入れる
  例「the smallest molecule that exists」一番小さい分子だから腎臓の細胞の中まで入れる（124529857）
- 〈人〉は〈この物〉を〈して〉はいけない。その理由はこう（自分の話かを、禁止の形で引っかける）

- 〈検査の名前〉で〈数字〉。〈同じ種類の物〉の〈割合〉は偽物

## 仮説「認知が進むほどリスティクルが増える」

**外れ。** リスティクルの割合は 気づいていない 17% → 問題に気づいている 30% → 解決策を知っている 21% → 商品を知っている 14% で、真ん中の「問題に気づいている」が一番多い。認知が進むほど増えたのは商品ページ（52% → 47% → 53% → 71%）。

## 新しい VSL と記事を組み立てる手順

1. 客の段階を1つ決める（書き出しで、客がもう知っている事は何か）
2. 書き出しの箱を決める。気づいていない・問題・解決策は 1 自分の話か、商品を知っている は 3 効くのか か 4 信用
3. 箱の順番を当てる。問題に気づいている は 1→2→3、解決策を知っている は 1→3（今の方法が効かない）→2 か 4
4. 商品を出す位置を決める。気づいていない・商品を知っている は書き出し、問題・解決策 は原因を言い切った後の真ん中
5. 一番大きい理由は 3 効くのか に置き、上のひな形から1つ選んで空欄を埋める（第一候補は「届かない → これは届く」）
6. VSL の最後は「それは何？／何をすればいい？」を答えずに残す
7. 記事の最初の段でその問いを受ける。問題に気づいている は 3 効くのか か 4 信用、解決策を知っている は 1 自分の話か
8. 6 損しないか と 7 値段 は記事で潰す
9. 記事の型は商品ページを基本にし、問題に気づいている の時だけリスティクルも試す
