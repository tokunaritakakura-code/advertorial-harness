# VSL と記事を段に分け、段ごとに潰した買わない理由を記録する

読む人: この作業を任された係。読む時: 始める前に全部。
材料: `形式別/manifest.tsv`（1行1広告）・`txt/<id>.txt`（VSL の台本）・`lp/<lp_file>`（飛び先の記事。`python3 -I ../lpread.py lp/<file> 60`。足りなければ python で本文の文字を抜く）。

## 手順（1本ずつ、この順）

1. VSL の台本を、頭から順に段に分ける。段ごとに、何を言ったかを1行と原文の引用を書く。商品が出てくる段には「商品が出る」と印を付ける
2. 段ごとに、その段で潰れた買わない理由を、下の7つの箱から全部付ける（1つの段に複数あってよい・無ければ空）。7つに入らない物は、新しい箱の名前を作って付ける
3. 段ごとに、その段が客に残した「なんで？」（言い切らずに残した問い）があれば書く
4. 飛び先の記事も同じように段に分け（見出しの順）、段ごとに 1〜3 を書く
5. VSL の書き出しと前提から、認知の段階を1つ決め、根拠の引用を書く
6. その広告の段のうち、潰した段の数が最も多い箱（同じ数なら台本の字数が多い方）と、それを潰した文（原文と日本語）を書く <!-- 掘った: 「最も多い」は段の数を数えて決める（母数＝その広告の段の数） -->

## 7つの箱
| 箱 | 客の頭の中の声 |
|---|---|
| 1 自分の話か | 「私には関係ない」「年のせいだから」 |
| 2 原因を信じられるか | 「本当の原因が分からない」 |
| 3 これで効くのか | 「なぜこれは効くの？」「今までの物と同じでは」 |
| 4 信用できるか | 「誰が言っているの」「本当？」 |
| 5 自分に合うか・続けられるか | 「痛くない？」「手間は？」「自分に使える？」 |
| 6 損しないか（リスクの引き受け） | 「合わなかったらお金がむだ」 |
| 7 値段と今買う理由 | 「この値段を払う価値がある？」「今じゃなくても」 |

## 認知の段階（5つ）
気づいていない／問題に気づいている／解決策を知っている／商品を知っている／買う直前

## 出力（1本＝JSON 1行、`買わない理由/組<N>.jsonl`）
```json
{"id":"…","brand":"…","段階":"…","段階の根拠":"引用",
 "VSL":[{"段":"書き出し","言った事":"…","引用":"…","商品が出る":false,"潰した箱":[1,2],"残したなんで":"…"}],
 "記事の型":"商品ページ／リスティクル／物語の記事／権威の暴露記事／事前販売ページ／医者のVSLページ／オファーページ／トップページ／読めなかった",
 "記事":[{"段":"…","言った事":"…","引用":"…","潰した箱":[4],"答えたなんで":"…"}],
 "一番大きい理由":{"箱":4,"原文":"…","日本語":"…","どこで":"VSL か 記事"}}
```
全部書いたら `python3 -c` で各行が JSON として読めるかを確かめる。返事は3行（書いた本数・読めなかった記事の数・新しく作った箱の名前）。
