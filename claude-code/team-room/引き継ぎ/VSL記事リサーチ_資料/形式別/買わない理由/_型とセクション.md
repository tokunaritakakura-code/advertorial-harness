# VSLと記事の型とセクション（194本）

材料: 同じフォルダの `組1〜7.jsonl`。数は全部そこから数えた。機械で読む版は `_型とセクション.json`（各セクションの「中身」＝チェックの項目と、潰す箱・例・id はそちら）。

箱: 1 自分の話か／2 原因／3 効くのか／4 信用／5 合うか・続くか／6 損しないか／7 値段と今買う理由

## セクションの辞書（14）

- **書き出しのつかみ**: 最初の数秒・見出しで手を止めさせる所
- **自分の話だと思わせる**: 症状や場面を当てて「私のことだ」と思わせる所
- **本当の原因**: なぜそうなっているのかを言い切る所
- **今までの物が効かない理由**: 客が試した物がなぜ駄目だったかを言う所
- **効く仕組み**: なぜこれは効くのかを言う所
- **証拠・研究**: 本当だと信じさせる材料を出す所
- **話している人・権威**: 誰が言っているか・どこで見つけたかの所
- **商品を見せる**: 商品の名前と、何をする物かを出す所
- **使い方・自分に合うか**: 手間・安全・自分に使えるかに答える所
- **結果・変化**: 使うと何が変わるかを見せる所
- **ほかの人の声**: 自分以外の客の声と数の所
- **値段・おまけ**: 値段と、得だと思わせる所
- **保証**: 合わなかった時に損しないと言う所
- **急がせる・締め**: 今買う理由と、次の行動を言う所

## 数え方

- セクション: VSLと記事の段（jsonl）ごとに、言った事を読んで辞書の名前を1〜3個付けた。1つの段に値段・保証・締めが同居する時は全部付けた
- 割合: その型の本数のうち、そのセクションを1回でも持つ本数の割合（%）。25%未満のセクションは載せない
- 中身の割合: そのセクションを持つ広告のうち、その中身を言っている広告の割合（%）。15%未満は載せない
- 潰す箱: そのセクションが付いた段の「潰した箱」（1〜7）を数えた上位2つ
- 並び: 各広告でそのセクションが初めて出る位置（0=頭、1=最後）の中央値の順
- 型の分け方: C=「日・週ごとの変化」の段が3つ以上（または「〜すると何が起きる」で始まり2つ以上）／D=商品が2段目までに出て、その前に原因・今までの物が無い（または4段以下で原因も今までの物も無い）／B=人の物語の一場面で始まり、人に教わる・周りが気づくがある／E=今までの物を切る段が原因より前で3段目までに出る／A=それ以外で本当の原因がある
