# VSL → 記事のつながり（リサーチまとめ 2026-10-08）

調べた物：X（あなたの保存21件・フィード・いいねした人の過去の投稿・検索7種）と、GetHookd の勝ち VSL。文字起こしと飛び先の記事を組で見た物は約30本。

## 1. 結論

**見る人が「どこまで分かっているか（認知段階）」が、VSL の骨組みと飛び先の記事の両方を決めている。**

あなたの仮説「Most aware に近いほどリスティクル」は、ほぼ当たり。リスティクルの飛び先を持つ VSL は、どれも「もう何かを試して失敗した人」に向けて話していた。

ただし、分かれ目がもう1つある。

- 失敗したのが「商品選び」の人 → **リスティクル**（「10の理由」「7つ試して1つだけ効いた」）
- 失敗したのが「やり方そのもの」の人（新しい原因・新しい仕組みが要る）→ **物語のアドバトリアル**（「本当の原因を見つけた」）

**広告と飛び先は、相手の人と切り口を1対1でそろえる。** Mars Men（4,512本）は商品ページにほとんど送っていない。「39歳の現場の親方」の広告からは親方向けのリスティクルへ、注射が怖い人向けの広告からは /trt-nervous へ送っている。

**飛び先の1段目は、VSL の続きになっている。** 例：Grounding の VSL「今履いているワースト4足」→ リスティクルの1番目の理由「あなたの"サポート靴"が悪化させている」。

## 3. VSL は「見た目」と「骨組み」の2段

### 3-1. 見た目（形式）

| 形式 | 向く物 | 実例 |
|---|---|---|
| 1人しゃべり（talking head・UGC） | まず台本を確かめる時。20〜40秒 | Elavate |
| 医者・専門家・現場の人（権威） | 原因を説明する健康の悩み | Sculptique、Veloma、Hike |
| 昔の権威（祖母・伝統医学） | 「昔は足りていた」型 | Everly（祖母）、Grounding（中国医学） |
| ポッドキャスト（2人の会話） | 説明が要る商品。疑う人が見る人の疑問を代わりに聞く | 一番長く走っていた広告は280日 |
| ポッドキャストの切り抜き | 敵を作る、借りた権威 | UndrDog |
| ドラマ・寸劇 | 「誰かが教えてくれた」を見せる | Koriderm（プールの女性2人） |
| タブーの物語（1人語り） | 女性向け。浮気・離婚から始める | Smooche、Rosalivia |
| 家族の証言 | 変化を他人の目で見せる | Mars Men（妻） |
| AI アニメ（ZackDFilms 風・Pixar 風・クレイ・黒板・体の上の小さいキャラ） | 見えない問題（体の中・肌の下） | Numoya、Mars Men（クレイ） |
| 創業者 | 値段・偽物の反論 | Peakflow、Sculpiflex |
| スタント・遊び | 安い物・衝動買い | Carpe（時速＝割引%） |

同じ骨組みを違う見た目で何本も撮るのが勝ちパターン。talking head で勝ったアングルを、ポッドキャストやアニメに作り替える。

### 3-2. 骨組み（台本の順番）5つ（Mars Men と RYZE の勝ち広告35本から）

1. **誰かが教えてくれた**：人に会う → その人が悩みを見抜く → 硬い証拠（数字や賭け）。商品名は後半
2. **時間で歩く**：「毎日飲むと何が起きるか」→ 1日目・1週目・14日目。段ごとに成分を1つ
3. **逆の警告**：「買うな」「効きすぎる」→ 欠点のふりをした得
4. **自分で仕分けるリスト**：「赤信号」「3タイプ、あなたは？」→ 語り手もそこにいた
5. **選びかけた怖い方**：注射・薬を医者が勧める → 避けた道と数字

**どれを選ぶか（上から順に見て、最初に当てはまる物）**：怖い選択肢と比べている→5／効果が日付で段になる→2／問題がサインやタイプで出る→4／カテゴリ自体を疑っている→1／すぐ効いて冗談にできる→3

### 3-3. 実物でよく出た流れ

書き出し（客の言葉で悩み、または意外な数字）→ 思い込みを「違う」で崩す → 本当の原因（たとえで見せる）→ 結果の積み上げ → 仕組み（成分1つずつ）→ 安物・偽物はだめ → 商品 → 証拠 → 保証と期限

## 4. 飛び先の種類と中の段

- **リスティクル（商品を比べる型）**：「〇〇をもう1つ試す前に読んで」→ 1番目の理由で今の物を否定 → 仕組み → 他でだめだった人にも効く → 専門家が作った → 保証。比較表を付ける事も多い
- **リスティクル（レビュアー型）**：「7つ試して1つだけ効いた」。1人称
- **物語のアドバトリアル**：フック → 今のやり方がだめな理由 → 本当の原因 → 仕組み（商品名なし）→ 証拠 → ここで商品。7割が教育
- **医者の長い VSL ページ**：高齢層・健康サプリ・3本／6本のまとめ買い
- **悩み別・人物別ページ**：広告の切り口1つにつき1枚
- **クイズ**：客のタイプが分かれる時（肌の型など）
- **創業者の反論ページ**：「詐欺？」に答える
- **商品ページ直行**：VSL だけで売り切れる時（勝ち長尺 VSL 80本中、約30本）

## 5. 作る時の流れ（あなたが足した部分）
