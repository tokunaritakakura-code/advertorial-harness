## なぜ良いのか（1行）

大手の漢方が、割引なしで「60秒の体質診断」を広告にしている。8タイプの名前・割合・アドバイスを返し、結果から「症状ボタン→漢方処方」へ進ませる。日本で英語型（多問・タイプ名）に一番近い1本。 `J`
